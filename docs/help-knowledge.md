# ידע לעוזר — מערכת המשימות

הטקסט שהעוזר (crm/server/helpBot.ts במאגר Haimbar1/CRM, מודול tasks) צריך לדעת על כל יכולת במערכת
המשימות. כל יכולת חדשה נכנסת לכאן ומשם לעוזר (ראו CLAUDE.md).

## ארכיון משימות (נוסף 2026-11-08)

- משימה שהסתיימה (בסטטוס סיום — למשל "בוצע" או "נדחה") עוברת לארכיון **לבד, שבוע אחרי תאריך הביצוע**.
- אפשר להעביר משימה שהסתיימה לארכיון גם מיד: פותחים את המשימה ולוחצים **"העבר לארכיון"** (בתחתית
  החלון, ליד "מחק משימה"). הכפתור מופיע רק במשימה בסטטוס סיום — משימה פתוחה לא נכנסת לארכיון.
- משימות בארכיון **לא מוצגות** ברשימות הרגילות (הטבלה, קנבן לפי סטטוס, קנבן לפי אחראי).
- כדי לראות אותן מסמנים **"כולל ארכיון"** בשורת החיפוש שמעל הרשימה. הן מופיעות אז יחד עם המשימות
  השוטפות, עם תגית אפורה "בארכיון". "✕ ניקוי" מבטל גם את הסימון.
- החזרה מהארכיון: מעבירים את המשימה לסטטוס פתוח, או לוחצים **"החזר מהארכיון"** בחלון המשימה. משימה
  שהוחזרה בכפתור לא תחזור לארכיון לבד עד שתסתיים שוב.
- קישור למשימה מהודעת וואטסאפ פותח אותה גם אם היא בארכיון.
- ביומן הפעולות (בגלגל השיניים) נרשם "משימה הועברה לארכיון" / "משימה הוחזרה מהארכיון".

שאלות מוצעות: "איך רואים משימות שבארכיון?", "למה משימה שביצעתי נעלמה מהרשימה?"
